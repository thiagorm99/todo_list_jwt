# 🚀 Todo List API - Spring Boot

API RESTful para gerenciamento de tarefas, desenvolvida com foco em boas práticas do ecossistema Spring, segurança e organização de código.

---

## 📌 Sobre o Projeto

Esta API permite o gerenciamento completo de tarefas (Todo List), com autenticação segura via JWT.

O projeto foi desenvolvido com foco em:

- Arquitetura limpa e organizada
- Boas práticas com Spring Boot
- Segurança de APIs REST
- Padronização de respostas

---

## ⚙️ Funcionalidades

- ✅ CRUD completo de tarefas
- 🔐 Autenticação e autorização com JWT
- 👤 Controle de usuários
- 📦 Padronização de respostas da API
- 📄 Documentação interativa com Swagger

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- JWT (JSON Web Token)
- Swagger (OpenAPI)

---

## 🔒 Segurança

A API utiliza autenticação baseada em JWT, garantindo:

- Proteção de rotas privadas
- Controle de acesso por usuário
- Stateless authentication
